## 一致版本读取协议

GitHub固定入口保持不变，但分支地址可能有缓存。需要最新已同步版本时，先读取免登录、禁止缓存的 [最新版本入口](https://ppt-layout-atlas.woollywave.chatgpt.site/api/public-manifest)，再读取其 manifest_url。此入口只返回公开版本信息，实际目录、卡片和图片仍从GitHub读取。

manifest.json 的 index、catalog、directory 和 files[].url 均锁定同一 catalogue_commit；条目的 preview 和 card 锁定 asset_commit。两个提交组成一个完整源版本，source_revision 必须一致。按这些完整URL读取，不要自行拼接 main 分支地址。核对 files[].sha256 和 images[].sha256；失败时重试同一固定提交，不能混用其他版本补文件。旧入口缓存命中时仍得到一份完整的旧快照；旧提交继续可读。
